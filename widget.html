Widget do Meu Ritual

Mostra treino, skincare, tarefas e contas de hoje na Tela de Início, no modo claro. Toque numa tarefa para marcar como feita. Este script se atualiza sozinho: só precisa colar uma vez.

Já tem o widget instalado? Abra o Scriptable, toque e segure o script Meu Ritual → Edit, apague todo o texto, cole o novo (botão abaixo) e toque em Done. Não precisa entrar de novo.
  1. Instale o app Scriptable na App Store (gratuito).
  2. Toque em Copiar script aqui embaixo.
  3. Abra o Scriptable, toque no + (canto de cima), cole o texto e toque no nome "Untitled Script" no topo para renomear para Meu Ritual. Toque em Done.
  4. Toque no script Meu Ritual para rodar e escolha Entrar: use o e-mail e a senha da sua conta do app (Ajustes → Conta). A senha não fica guardada, só uma chave de acesso no Chaveiro do iPhone.
  5. Na Tela de Início, segure num espaço vazio → Editar → Adicionar Widget → Scriptable → escolha o tamanho médio ou grande → Adicionar Widget.
  6. Segure o widget → Editar Widget → em Script escolha Meu Ritual. Em "When Interacting", deixe Run Script.

Ao tocar numa tarefa, o Scriptable abre por um instante, marca a tarefa e mostra "Feito". Volte para a Tela de Início: o iPhone atualiza o widget em alguns minutos (é ele quem decide a hora).
